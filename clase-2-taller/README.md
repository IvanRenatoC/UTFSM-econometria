## Generar y trabajar

Desde la raíz del curso:

```sh
python3 clase-2-taller/herramientas/generar_web.py
```

Para ejecutar R, trabaja desde `clase-2-taller/`, junto a `datos/`. Abre el notebook con kernel R. Las láminas, las celdas y la guía se generan desde `contenido-clase-2.json` para conservar el mismo orden.
